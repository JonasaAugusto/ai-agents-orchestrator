# Code of conduct

This applies to project issues, pull requests, discussions and other project-managed spaces, including maintainers.

Be respectful, give actionable technical feedback, welcome different experience levels, and respect privacy.
Harassment, threats, discriminatory language, sexualized attention, doxxing and deliberate disclosure of private
information are unacceptable. Critique the work; do not attack its author. Stop unwanted contact when asked.

To report public abusive content, use GitHub's **Report content** menu on the issue, comment or pull request:
[GitHub reporting guidance](https://docs.github.com/en/site-policy/abuse-and-spam/reporting-abuse-or-spam).
For a private maintainer conversation, request a private contact without posting identifying details or evidence
in public. If the concern involves a maintainer, use GitHub's reporting channel directly. Security vulnerabilities
have a separate private route in [SECURITY.md](SECURITY.md).

Maintainers may edit or remove abusive contributions, warn participants, restrict participation or block accounts,
according to severity and repeated behavior. They should protect reporter privacy and explain moderation decisions
without exposing private evidence. This project cannot promise a response deadline or control spaces it does not manage.
